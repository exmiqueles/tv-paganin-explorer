TV–Paganin explorer v

Interactive companion to “A total-variation extension of Paganin-method phase retrieval and its flux-field interpretation” (E. X. Miqueles & D. M. Paganin). Everything runs locally in your browser.

1 · Data

Input must be the normalized ratio r = I/I₀. .npy (2D, numeric) is preferred; 8-bit images are read as gray/255. Non-finite values are rejected.

5 · Effective diffusivity D

Minimizes ½⟨|ℓTVp − ℓPAG∇u + z²∇(Du)|²⟩ + ½α⟨|∇D|²⟩ + ½β⟨D²⟩ over D ≥ 0 (⟨·⟩: pixel mean), with u, p and ℓTV of the last TV run.

Presets set every parameter (data, region, Paganin, TV and D). The paper's Fig. 4 uses β = 10⁻¹…10⁻⁴; the presets use β = 10⁻².

File names share the run id. The metadata file records data, region, the parameters actually used, stopping criteria, convergence status and staleness of every result.
